# Support and maintenance

Agent Debate Engine is an alpha, best-effort open-source project. It has no support SLA, hosted
service, or compatibility guarantee for unverified provider CLI versions.

## Supported surface

- Python 3.11–3.13 on Linux and macOS.
- The documented schema-v1 configuration and run formats.
- The read-only Codex preset generated by `agent-debate init`.
- The provider versions and permission contracts explicitly listed in the README and security model.

Run `agent-debate doctor` after upgrading a provider CLI. A successful doctor check establishes
command compatibility only; it does not certify provider behavior or data handling.

## Best-effort surface

- Bug reports with a minimal reproduction using fake executables or sanitized inputs.
- Focused changes that preserve the ordered debate protocol, deterministic stopping, bounded
  resources, and immutable audit evidence.
- Documentation corrections and small, well-tested provider adapter updates.

## Out of scope

- Debugging private prompts, credentials, employer repositories, or undisclosed provider
  configuration.
- Support for unsafe Kimi or Generic execution without an external containment boundary.
- Windows guarantees, hosted orchestration, project management, arbitrary DAGs, or shared
  code-writing worktrees.
- Operational or legal advice based solely on a model-generated debate.

Never attach `.agent-debate/` directories to public issues. They can contain task text, source
excerpts, local paths, prompts, outputs, and provider diagnostics. Follow [SECURITY.md](SECURITY.md)
for vulnerabilities and [CONTRIBUTING.md](CONTRIBUTING.md) for proposed changes.
